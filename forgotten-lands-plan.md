## How it differs from Brume

Brume was a few levels on the mod base. TFL is a whole-game overhaul: 336 "TFL note" edits in ~130 engine / vanilla
level files, besides its own levels.

| Area | TFL | Brume |
|---|---|---|
| Levels | 5: crystal-cave (CRC), crescent-top (CST), energy-bay (ENB), open-mines (OPM), valley (VAL) + test-zone (skip) | 4 |
| Custom models | ~35 (custom_levels/*.glb: gondola, turbine, PDS sentinel boss + traps/gems/plats, crystals, commentary nodes, title logo...) | 3 |
| Draco | 5 of 46 glbs | all |
| Tasks | mod 116-149 (34) -> ours 151-184, max 185 | 123-150 |
| Text | #x10c4-#x10c8, #xa01-#xa6x, #xb..., #x1525 (check collisions) | #x4620- |
| New player mechanic | super eco (4 colours: crystals, super red bomb, super yellow charged shot, super blue air control, super green invuln) through target, target-h (new fields), fact-h pickup-type, game-info, powerups, hud, crates, collectables, plat-eco, projectiles, nav-enemy freeze state, racer | none |
| Engine type layouts | target, collide-target, camera-bank, level-load-info (customname / orb / buzzer counts), target-racer, projectiles, process-drawable, gkernel-h, load-boundary flags | none |
| Vanilla actors | res-lump tweaks in misty-conveyor (new keg bounces), minecart, quicksandlurker, swamp-bat, snow-bunny, battlecontroller, rolling-robber, race rings (orange/green), balloonlurker (curve-control), cave-trap / baby-spider (tfl- types), bully, bonelurker, ice-cube, sun-iris-door, target-tube, driller-lurker | a few |

| Particles | ids up to 4183; table raised 3584 -> 8192, groups 1024 -> more | fits |
| Ocean | crescent-top / energy-bay / open-mines / valley use a custom *ocean-map-crescent-t* (ocean-tables) | none |
| Mood | custom mood tables + update-mood funcs per level | stock |
| Engine misc | birth-dist 220 -> 500 m, per-actor 'scale and 'vis-dist-hack lumps (entity.gc), 'texscroll-dist (bones), load-boundary ignore-normal/racing/flut flags, art-group dir 50 -> 60, 3+ sound banks at once, main-thread stack 1024 | - |
| Audio | 6 music mp3s (tfl-music-player, incl. boss), ~40 NEW voice-acted hint wavs (tfl-hint + subtitles), ~80 developer-commentary mp3s (commentary nodes + menu) | 4 tracks, disc voices |
